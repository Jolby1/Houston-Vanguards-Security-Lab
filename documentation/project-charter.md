# Houston Vanguards Hybrid Identity Security Engineering Lab

## Project Purpose

This project exists to transform my cybersecurity resume from an experienced security analyst profile into a credible **IAM/PAM Engineer with Azure security engineering capabilities**.

The goal is not to build a simple homelab.

The goal is to create a realistic enterprise security engineering environment where I can demonstrate that I can:

- Architect security environments
- Build and integrate identity systems
- Automate security workflows
- Write production-quality PowerShell/Python automation
- Work with Microsoft Azure and Microsoft Entra ID
- Integrate systems through APIs
- Secure privileged and non-human identities
- Implement RBAC/PIM concepts
- Deploy infrastructure through code
- Troubleshoot failures independently
- Document engineering decisions professionally

The final output should be a showcase-level GitHub portfolio project that improves my ability to compete for:

- IAM/PAM Engineer
- Senior Information Security Analyst

- Identity Engineer
- Security Engineer

Metrics must be real.

- Time
- Systems involved
- Manual decisions
- Errors

- Automation percentage

- Failures handled
- Objects processed

Before:

```

3 systems
18 minutes

After:

```
Automated workflow
3 systems integrated
Measured execution time
